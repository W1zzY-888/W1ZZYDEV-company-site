# RU Staging Server Requirements

Minimum:
- Linux server;
- amd64 or arm64 architecture;
- 2 CPU cores;
- 2 GB RAM;
- 20 GB disk plus backup storage;
- Docker Engine;
- Docker Compose plugin;
- firewall allowing only HTTP/HTTPS and SSH;
- DNS A/AAAA record for `RU_API_DOMAIN`;
- TLS certificate and renewal process;
- external or mounted secret storage;
- backup destination with retention.
